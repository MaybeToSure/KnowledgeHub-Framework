# 元数据规范

正式 Markdown 条目使用 YAML frontmatter：

```yaml
---
id: knowledge/example-id
title: 示例标题
type: knowledge
status: active
authority: codex
locked: false
created_by: codex
created_at: 2026-01-01T00:00:00+08:00
updated_by: codex
updated_at: 2026-01-01T00:00:00+08:00
topics: []
projects: []
sources: []
---
```

## 必填字段

- `id`：稳定标识；移动文件时保持不变。
- `title`：人工可读标题。
- `type`：使用治理规则中的知识类型。
- `status`：`inbox`、`active`、`needs-review` 或 `archived`。
- `authority`：`human` 或 `codex`。
- `locked`：人工是否锁定核心内容。
- `created_by`、`created_at`、`updated_by`、`updated_at`：来源追踪。

## 关联字段

- `topics`：主题标识列表。
- `projects`：关联项目 ID 列表。
- `sources`：来源条目 ID、相对路径或稳定 URL。

事实、推断和待验证内容应在正文中明确区分。没有来源的 AI 推断不得标记为已确认事实。
