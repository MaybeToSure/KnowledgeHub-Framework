# 仓库同步契约

## 权威与同步

- 本地仓库是日常工作副本。
- 用户配置的 Git 远程主分支是已同步内容的远程基线。
- “完整同步”要求普通 Git 对象、Git LFS 对象和提交引用全部成功上传。

## 自动同步流程

1. 检查工作区状态和未跟踪文件。
2. 运行知识库健康检查。
3. 暂存符合规则的变更。
4. 创建说明明确的提交。
5. 拉取远程更新并进行非破坏性整合。
6. 无冲突时推送；有冲突时停止并保留双方内容。
7. 验证本地分支与远程分支一致，检查 LFS 对象状态。

## 禁止项

- `git push --force` 或等价历史改写。
- 把密钥和本地缓存加入提交。
- 在没有恢复点的情况下批量删除、移动或重命名。
- 把“命令执行成功”当成恢复完整性证明；重要知识库应定期进行全新克隆验证。
