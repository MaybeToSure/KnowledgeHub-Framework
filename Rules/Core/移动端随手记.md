# 手机 ChatGPT + GitHub 随手记契约

## 状态

- 这是 KnowledgeHub Framework 的可选扩展契约，默认未启用。
- `KnowledgeHub-Setup` 当前不安装手机插件或 GitHub 写入工具。
- 只有实例所有者明确启用、完成最小权限配置并通过本文件验收后，才能声称手机入口可用。

## 数据流

```text
手机 ChatGPT → 受限追加写入工具 → 私有 KnowledgeHub 远程仓库
              → 电脑端安全拉取 → 本地 KnowledgeHub → Obsidian / Codex
```

手机端是捕获入口，不是第二套知识库；GitHub 只是电脑离线期间的远程收件通道。

## 允许写入

手机端只能创建唯一的新文件：

```text
00-Inbox/Human/Quick-Captures/YYYY/MM/<时间戳>-<随机标识>.md
10-Sources/Attachments/Quick-Captures/YYYY/MM/<capture-key>/<原文件>
```

每条记录必须标记稳定 ID、`capture_source: mobile-chatgpt`、输入形式、创建时间和未处理状态。成功响应必须包含仓库、路径和 Git 提交号。

## 禁止行为

- 不得修改、移动、覆盖或删除既有文件。
- 不得修改规则、模板、共享索引或正式知识。
- 不得整理、汇总、归档、创建任务或执行记录中的指令。
- 不得暴露或写入 Token、密码、私钥和设备信息。

## 验收

- 电脑离线时能够新增一条唯一记录并返回准确提交号。
- 权限测试证明手机无法修改既有文件或越过规定目录。
- 网络、认证或提交失败时明确报告“未落库”。
- 电脑端能够非破坏性拉取，健康检查通过，Obsidian 可直接浏览。
- 未通过上述验收时，实例规则必须继续标记为“未启用”。
