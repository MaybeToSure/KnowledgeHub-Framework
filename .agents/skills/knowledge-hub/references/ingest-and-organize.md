# 资料注入与整理

## 注入

1. 确认输入是原始资料、人工笔记还是 AI 派生内容。
2. 原始文件保持原样放入 `10-Sources`，必要时使用主题子目录。
3. 根据 `Templates/Core/来源条目.md` 创建来源记录，保留原路径、网址、作者、获取时间和摘要。
4. 可复用结论另建 `20-Knowledge` 条目，不把推断写成来源原文。
5. 暂时无法判断的内容进入相应 `00-Inbox`，不得伪造分类确定性。

## 整理

- 优先依靠元数据和稳定 ID 建立多重关联，不复制同一资料到多个课程或项目目录。
- 移动文件前搜索 Markdown 链接和 `sources`、`projects` 引用；移动后修复并验证。
- 合并重复条目时保留较完整的稳定 ID、来源和历史，另一条移入 `90-Archive` 并记录重定向。
- AI 生成内容设置 `authority: codex`；人工原文默认 `authority: human`。
- 用户在 `Rules/Local` 和 `Templates/Custom` 中的约定优先于核心默认值。

## 验收

- 原始资料存在且可读取。
- 来源、创建者、时间、主题和关联可追溯。
- 没有因整理产生断链或无来源的确定性结论。
