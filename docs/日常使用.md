# 日常使用

## 人工记录

- 不知道放哪里：保存到 `00-Inbox/Human`。
- 原始 PDF、课件、图片：保存到 `10-Sources`，附件默认在 `10-Sources/Attachments`。
- 明确是过程思考：保存到 `30-Notes`。
- 人工拥有最高权限；要禁止 AI 改写核心内容时，在 frontmatter 中设置 `locked: true`。

## 人工查找

1. 知道标题：使用 Obsidian 快速切换器。
2. 知道关键词：使用全文搜索。
3. 知道内容类型：浏览对应一级目录。
4. 只记得模糊含义或需要综合多份资料：让 Codex 检索。
5. 知道项目或课程：从 `50-Projects` 或 `40-Courses` 的入口沿链接查找。

## Codex 常用自然语言

```text
把这些资料收进知识库，建立来源记录并提取可复用知识。
```

```text
找出与设备身份认证有关的文献、实验和项目决策，区分事实、推断和缺口。
```

```text
审核最近新增的知识，检查来源、重复、矛盾、失效链接和过期结论，然后同步远程。
```

```text
根据知识库中的资料为新代码项目组装最小上下文，并在 50-Projects 创建项目入口。
```

## 项目协作

代码项目和知识库逻辑关联、物理分离：

```text
<工作区>/
├─ My-KnowledgeHub/
└─ example-project/
```

代码、测试和项目专属文档留在项目仓库；可跨项目复用的方法、决策、实验结论和验证证据回流知识库。
