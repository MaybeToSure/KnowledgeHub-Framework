# 快速开始

## 目标

用同一个本地目录连接人工、Obsidian、Codex 和 Git；用户不需要先理解全部规则就能开始记录和整理。

## 从 GitHub 模板创建

1. 在框架仓库页面选择 **Use this template**。
2. 创建一个新的私有仓库，例如 `My-KnowledgeHub`。
3. 克隆该仓库并进入根目录。
4. 运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\tools\setup.ps1
   ```

5. 用 Obsidian 打开根目录。
6. 用 Codex 打开同一目录。

`setup.ps1` 不会推送远程，也不会覆盖已有的 Obsidian 设置；它只补齐缺失配置。

## 从 ZIP 创建

解压后在根目录运行同一条初始化命令。脚本会在缺少 `.git` 时创建 `main` 分支并启用 Git LFS。然后由用户自行创建私有远程仓库并关联。

## 首次验证

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\verify-repository.ps1
```

看到 `VERIFY_OK` 表示目录、Git、Git LFS 和基础安全检查均通过。

## 第一个任务

把文件放入 `00-Inbox/Human`，然后对 Codex 说：

```text
整理收集箱中的新增资料。保留原始内容，补充元数据和关联；无法确定的继续留在收集箱。
```
